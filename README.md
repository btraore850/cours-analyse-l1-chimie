# Analyse — Licence 1 en Chimie

Site de ressources pédagogiques de **M. Bakary TRAORE**, Université de N’Zérékoré.

## Site du cours

https://btraore850.github.io/cours-analyse-l1-chimie/ (après activation de GitHub Pages)

## Dossiers pédagogiques

- `polycopie-du-cours/` — Polycopié du cours : Cours rédigés par chapitre : définitions, propriétés, méthodes, démonstrations et exemples.
- `presentation-beamer/` — Présentation Beamer : Diaporamas destinés à l’enseignement magistral et aux révisions.
- `td/` — TD : Feuilles d’exercices guidés, problèmes d’entraînement et travaux dirigés.
- `tp/` — TP : Travaux pratiques et activités d’application avec les outils de calcul.
- `application/` — Application : Études de cas où les méthodes mathématiques sont appliquées aux phénomènes chimiques.
- `bibliographie/` — Bibliographie : Manuels de référence, ouvrages universitaires et ressources de lecture complémentaires.

Les fichiers `index.html` assurent la navigation web ; les six dossiers ci-dessus sont les seuls dossiers de contenu pédagogique.

## Ajouter un support de cours

1. Ouvrir le dossier correspondant dans le dépôt GitHub.
2. Cliquer sur **Add file → Upload files**.
3. Déposer le fichier (PDF, TeX, présentation, etc.) puis **Commit changes**.
4. Le fichier sera ensuite listé automatiquement dans sa rubrique sur le site, grâce à l’API publique GitHub.

## Activer le site GitHub Pages

**Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.

Les images de l’en-tête sont chargées depuis le site modèle d’Analyse en Hydrologie pour respecter la structure de six dossiers seulement.
